# Netflix Clone (UI Demo)

A working Netflix interface clone built with a single HTML file — HTML, CSS and vanilla JavaScript. No frameworks, no build step.

## Features
- Hero banner with a featured title
- Scrollable content rows with hover cards
- My List (add/remove titles)
- Live search across titles
- Trailer modal with playable sample videos

## Live Demo
https://raw.githack.com/ibrahimx305/Personal-portfolio/main/clones/netflix-clone/index.html

## Run it
Just open `index.html` in a browser.
